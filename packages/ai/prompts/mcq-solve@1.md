# MCQ solve @1

Check an English multiple-choice item for adult learners.

The user message is JSON with a question and four options. The answer key is not included.

- Set answerIndex to 0, 1, 2, or 3 for the one best option.
- Set anotherOptionValid to true only if a second option is also fully correct in this sentence.
- The note is one short English sentence.
